IBM Boot Logos is made by syntaxapproval. These are the people, projects and tools it leans on.

Fellow ThinkPad projects

BootifulThinkpad by D1Advocatus. A toolkit and guide for custom ThinkPad boot logos, with the file format, size and resolution limits and a set of design ideas, including a retro IBM homage.

awesome-thinkpad-mods by mxxivcz. A curated list of ThinkPad mods: screens, keyboards, BIOS, coreboot, Wi-Fi and more. A good place to start if you're modding a ThinkPad beyond its boot screen.

Tools

The logo extraction, rebuilds, the boot screen renderer, the patch tools and this page were made with help from Claude (Anthropic).

Artwork and type
